## Abelian at a glance

Abelian's hybrid proof-of-work model uses two mining algorithms: ABEL-ETHash and ABEL-Nakamoto. The project documentation describes them as quantum-resistant and outlines their different hardware goals in the [mining FAQ](/en/faq/community/pow-mining).

The network uses post-quantum, lattice-based cryptography. Abelian's privacy options let users transact transparently, privately, or with auditable privacy. The [wallet documentation](/en/wallet/desktop-wallet) and [Abelian Name Service API](/en/build/ans-api) cover related wallet and address workflows.

## Get help and contribute

Use the documentation search to find pages by keyword. If you find an error or want to contribute an experience, open-source project, or tool, [open an issue on GitHub](https://github.com/pqabelian/abelian-community/issues/new). Contributions can be anonymous or attributed.

For help from the community, join the [Abelian Discord](https://discord.gg/Rrb33mC3Kc). The community recommends submitting a ticket in the Ticket channel when you need support.
