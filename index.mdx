# Hello Builders 👋
Abelian is a quantum-resistant privacy blockchain. It gives individuals private money and lets companies work with confidential, auditable assets. Use these docs to understand the network, choose a wallet, build integrations, or operate infrastructure.

Build apps that stay safe, even after quantum computers arrive. Abelian has used post-quantum security since day one, and privacy is built in, so your users decide how much of each transaction others can see. You focus on building; the network handles the hard parts.

## Questions or contributions?

Search these docs by keyword. To report an error or contribute an experience, open-source project, or tool, [open a GitHub issue](https://github.com/pqabelian/abelian-community/issues/new). Contributions can be anonymous or attributed. For community support, join the [Abelian Discord](https://discord.gg/Rrb33mC3Kc) and submit a ticket in the `support-ticket` channel.
