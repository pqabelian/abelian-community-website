Hako Metal's current homepage presents the **Hakometal20**, described as its Gen 2 ASIC miner for Abelian's NIST SHA3-Nakamoto proof-of-work algorithm. The device is designed for home use and connects over Wi-Fi.

## Current Hakometal20 specifications

| Specification | Manufacturer listing |
| --- | --- |
| Algorithm | NIST-SHA3-Nakamoto |
| Network | Abelian mainnet |
| Hashrate | 1,650–2,100 GH/s |
| Power consumption | 38–42 W |
| Weight | 0.65 kg |

Hako Metal notes that hashrate is based on standard laboratory testing and actual performance can vary with input voltage, ambient temperature, cooling, and other operating conditions. See the [Hakometal20 listing](https://hakometal.xyz/) for current specifications and availability.

## Pool and setup

Hako Metal's published setup guide for **HAKO METAL Genesis** describes connecting the miner to 2.4 GHz Wi-Fi, creating an account on the [ABEL-Nakamoto Pool](https://abel-nakamoto.xyz/), and entering the pool credentials in the miner's web interface. The guide identifies its device as Genesis, so confirm the correct setup instructions for your Hakometal20 model with [Hako Metal](https://hakometal.xyz/guide/hako-metal) before proceeding.

The guide also recommends preparing an Abelian wallet address to receive mining rewards. Keep pool credentials private, and never share wallet private keys or recovery phrases.
