Abelian 改進提案（Abelian Improvement Proposals，簡稱 AIP）是提出、討論和記錄 Abelian 區塊鏈生態系統改進的結構化文件。提案會說明具體的變更或問題、提出原因，以及協助社群審閱和實作的技術細節。

## AIP 涵蓋的類型

AIP 儲存庫將提案分為三種類型：

- **標準類（Standards Track）**：描述可能影響網路行為或相容性的技術標準或變更。
- **資訊類（Informational）**：記錄 Abelian 生態系統的資訊或指引。
- **流程類（Process）**：描述專案或社群使用的流程與程序。

每份提案都有狀態，例如 Draft（草案）、Proposed（提議中）、Final（定稿）、Active（生效中）、Rejected（未採納）、Deprecated（已棄用）或 Superseded（已被取代）。狀態代表提案在 AIP 流程中的階段或現況；提案獲得接受本身並不會使其自動成為網路標準。是否採用仍取決於 Abelian 社群與使用者的共識。

## 閱讀與參與討論

請前往 [Abelian AIP GitHub 儲存庫](https://github.com/pqabelian/aips) 瀏覽提案文件、狀態資訊和貢獻指引。若要提出新提案或參與討論，請使用儲存庫的 [Issues 討論區](https://github.com/pqabelian/aips/issues)。
