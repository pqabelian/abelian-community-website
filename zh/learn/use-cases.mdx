## 支付

行動多資產錢包可同時管理 ABEL、BTC、ETH、USDT 和 USDC，並在錢包內兌換。偽匿名地址可用於交易所和商戶支付；其他情況則可使用完全私密地址。

## 穩定幣

使用 AUT 標準發行代幣，代幣即可沿用 Abelian 網路的隱私層級與抗量子能力，作為無需在發行文件中預先規劃密碼學遷移的結算資產。

## Layer 2 與智慧合約

QDay Network 是與 EVM 相容的 Layer 2，並從 Abelian 繼承後量子結算能力。你可以沿用現有的 Solidity 工具鏈部署，並以能因應長期密碼學需求的技術完成結算。

## 現實世界資產

代幣化債券、基金和所有權紀錄可能需要維持十至三十年。這些資產可預設為機密，並透過檢視金鑰向稽核人員揭露，同時以密碼學方式驗證，即使 ECDSA 不再獲准使用也能維持有效性。

## 機構託管與合規

部分檢視金鑰可讓託管機構或監管單位查驗餘額和資金流向，而不取得支出權限，讓隱私機制也能配合合規審查。
