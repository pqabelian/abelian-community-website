使用本指南選擇挖礦方式、安裝 ABEL-ETHash GPU 客戶端、設定顯示卡並監控挖礦效能。

如需設定節點，請參閱 [Abelian 節點指南](/zh/operate/nodes/abelian-node)。

訪問 Abelian 官方網站的下載頁面以下載適當的挖礦客戶端。

所有操作均透過命令列介面 (CLI) 進行。對於 Linux，請開啟終端機；對於 Windows，請開啟 PowerShell 或您選擇的任何殼層應用程式。

## 概述

在 Abelian 上進行 ABEL-ETHash GPU 挖礦可以透過兩種方式進行：

- **獨立挖礦**：使用您自己的 Abelian 節點獨立挖礦，保留所有區塊獎勵
- **礦池挖礦**：加入礦池與其他礦工分享計算工作和獎勵

## 前置需求

### 系統需求

| 組件       | 獨立挖礦                     | 礦池挖礦                     |
|------------|------------------------------|------------------------------|
| **GPU**    | NVIDIA/AMD GPU，8GB+ 顯存    | NVIDIA/AMD GPU，4GB+ 顯存    |
| **儲存空間** | 200GB+ (用於 Abelian 節點)   | 100MB (僅客戶端)             |
| **記憶體** | 8GB+                         | 4GB+                         |
| **網路**    | 穩定的寬頻連線               | 穩定的寬頻連線               |

### 選擇您的挖礦方式

**獨立挖礦：**

- ✅ 保留 100% 的區塊獎勵
- ✅ 支援網路去中心化
- ❌ 需要運行 Abelian 節點
- ❌ 不規律的獎勵（高變異性）
- **最適合**：擁有顯著 GPU 算力的礦工

**礦池挖礦：**

- ✅ 規律、可預測的獎勵
- ✅ 無需運行 Abelian 節點
- ✅ 較低的硬體需求
- ❌ 與其他礦工分享獎勵
- ❌ 礦池費用（通常為 1-3%）
- **最適合**：GPU 算力有限的礦工

## 獨立挖礦設定

### 1. 安裝 Abelian 節點

首先，您需要一個運行中的 Abelian 節點。請遵循 [Abelian 節點指南](/zh/operate/nodes/abelian-node) 設定 `abec`。

**`abec.conf` 中挖礦的關鍵設定：**

```ini
# 節點類型
# 請注意，普通節點足以進行挖礦
nodetype=normalnode 

# 啟用挖礦支援
enablegetwork=1

# 允許遠端挖礦連線（如需要）
rpclistengetwork=:8668

# 設定您的挖礦獎勵地址
miningaddr=[your wallet address]
```

**確保 Abelian 節點已同步。**

### 2. 安裝 GPU 挖礦客戶端

下載 [ABEL-ETHash GPU 挖礦客戶端](/zh/downloads/latest#abel-ethash-顯示卡挖礦客戶端) 並解壓縮：

```text
~/abel/abelminer-linux-amd64-v2.0.4/
```

### 3. 建立錢包地址

您需要一個錢包地址來接收挖礦獎勵。最簡單的方法是使用 [Abelian Pro](/zh/downloads/latest#abelian-移動應用)：

1. 下載並安裝 Abelian Pro
2. 建立新錢包或匯入現有錢包
3. 導航至 `個人資料 → 帳戶詳情`
4. 點擊地址欄位旁的眼睛圖示
5. 複製您的錢包地址

### 4. 開始獨立挖礦

導航至挖礦客戶端目錄並運行：


**Windows**

```powershell
$ .\abelminer.exe -P http://localhost:8668
```

**macOS/Linux**

```shell
$ ./abelminer -P http://localhost:8668
```

**若要連接遠端 Abelian 節點：**

**Windows**

```powershell
$ .\abelminer.exe -P http://[node-ip]:8668
```

**macOS/Linux**

```shell
$ ./abelminer -P http://[node-ip]:8668
```

## 挖礦客戶端設定

### 基本參數

**連接選項：**

- `-P http://host:port` - HTTP 連接（獨立挖礦）
- `-P stratums://user:pass@host:port` - 安全 stratum 連接（礦池挖礦）

**GPU 選擇：**

- `--cuda-devices 0,1,2` - 選擇特定的 CUDA 裝置
- `--opencl-devices 0,1` - 選擇特定的 OpenCL 裝置

**效能調整：**

- `--cuda-grid-size 8192` - 調整 CUDA 網格大小
- `--cuda-block-size 256` - 調整 CUDA 區塊大小

### 設定範例

**使用特定 GPU 進行獨立挖礦：**

```shell
$ ./abelminer -P http://localhost:8668 --cuda-devices 0,1
```

**進行效能調整的礦池挖礦：**

```shell
$ ./abelminer -P stratums://user:pass@emily-service.abelian.info:27778 --cuda-grid-size 8192
```

## 監控與最佳化

### 效能指標

挖礦時監控這些關鍵指標：

- **算力**：您的挖礦速度 (H/s, KH/s, MH/s)
- **接受的分享**：成功提交的工作
- **拒絕的分享**：盡量低於 `2%`
- **GPU 溫度**：保持在 80°C 以下
- **功耗**：監控效率

### 最佳化提示

**硬體最佳化：**

- 確保 GPU 有足夠的散熱
- 盡可能使用專用挖礦設備
- 考慮降低電壓以提高效率
- 監控 GPU 記憶體溫度

**軟體最佳化：**

- 定期更新 GPU 驅動程式
- 使用最新的挖礦客戶端版本
- 嘗試調整網格/區塊大小
- 監控系統資源使用量

**網路最佳化：**

- 使用穩定的網路連線
- 考慮使用多個礦池伺服器作為備援
- 監控到礦池伺服器的延遲

**連線問題：**

- 調整挖礦參數
- 確認電源供應充足

**高拒絕率：**

- 檢查網路穩定性
- 確認系統時間同步
- 監控 GPU 穩定性
- 考慮降低超頻設定

## 安全考量

### 錢包安全

- **絕不分享**您的私鑰或助記詞
- **使用專用挖礦地址**，與主錢包分開
- 在開始挖礦操作前**備份錢包**
- 在提供憑證前**驗證礦池真實性**

### 網路安全

- 遠端挖礦時**保護 RPC 連線**
- **使用防火牆規則**限制挖礦埠存取
- **監控挖礦活動**以發現異常行為
- **保持軟體更新**至最新版本

## 經濟與獲利能力

### 影響獲利能力的因素

- **算力**：您的挖礦速度
- **網路難度**：每 200 個區塊調整一次
- **區塊獎勵**：目前每區塊 64 ABEL（第二紀元）
- **電力成本**：主要營運費用
- **硬體效率**：每瓦特算力比

### 計算回報

**獨立挖礦：**

- 獎勵 = (您的算力 / 網路總算力) × 區塊獎勵 × 每日區塊數
- 高變異性 - 可能不規律地找到區塊

**礦池挖礦：**

- 獎勵 = 您的貢獻 × 礦池獎勵 × (1 - 礦池費用)
- 低變異性 - 定期支付

使用線上 [算力計算機](https://maxpool.org/home/hash-rate-calculator) 並在 [AbelScan](https://explorer.pqabelian.io) 監控網路統計資料
