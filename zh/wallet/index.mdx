# 你的資產，由你掌控

Abelian Pro 是管理數位資產的一站式錢包。你可以在應用程式中持有 ABEL，以及 Bitcoin、Ethereum 等其他貨幣，並直接在應用程式內兌換，無需在不同平台之間切換。傳送 ABEL 時，你可以透過多層隱私選擇每筆交易的隱私程度：透明模式適合快速、低成本的公開轉帳；遮蔽模式則會保密交易細節。錢包採用後量子密碼學保護，並可透過簡單的復原助記詞取回資金，讓你始終掌控自己的資產。
